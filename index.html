NEW RESEARCH / 2026.10.29

로컬 LLM으로 사내 문서에 근거해 답하기

로컬 실행 프로토타입·실측 결과

  1. 모델 — 공식 Qwen2.5-1.5B-Instruct Q4_K_M을 llama.cpp / Metal로 실제 추론. 자체 모델 학습이 아닙니다.
  2. 방법 — 합성 사내 문서 7개·8절을 문자 n-gram TF-IDF로 검색해 답변 문맥에 추가했습니다.
  3. 기능 — 한국어 질문, 근거 원문, 답변, 검색·생성 시간, 잘못된 인용 경고와 근거 부족 응답을 구현했습니다.
  4. 제품 — 동일 Mac 브라우저에서 실행하는 연구용 앱. 공개 서비스·원격 데모는 제공하지 않습니다.
1 / 10 → 10 / 10검색 없음 → RAG
내용·보류 휴리스틱 통과

고정된 합성 질문 10개 × 2조건 = 실제 생성 20회. 답변 가능 7개·불가 3개, seed 42·temperature 0, 조건별 문항당 1회입니다. 독립적인 사람 평가가 아닌 키워드·보류 휴리스틱이며 일반 정확도나 보편적 벤치마크가 아닙니다. 과거 경력·고객 운영 실적으로 표현하지 않습니다.
